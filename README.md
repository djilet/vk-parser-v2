# VK Chat Bot — получение access token

Работа с [vkhost.github.io](https://vkhost.github.io/).

## Установка

```bash
npm install
```

## Команды

### Создать сессию (вручную)

```bash
npm run vk:session
npm run vk:session -- --browser 2
```

### Получить и сохранить токен

```bash
npm run vk:token
npm run vk:token -- --browser 2
npm run vk:token-all   # по очереди для браузеров 1 и 2
```

### Работа с сохранёнными токенами

```bash
npm run vk:tokens              # список всех токенов
npm run vk:show -- --browser 1 # показать токен браузера
npm run vk:get -- --browser 1  # вывести только access_token (для скриптов)
```

## Несколько браузеров

Два независимых профиля: **1** и **2**.

| Браузер | Сессия | Токен |
|---------|--------|-------|
| 1 | `.browser-profile-1/` | `tokens/browser-1.json` |
| 2 | `.browser-profile-2/` | `tokens/browser-2.json` |

```bash
VK_BROWSER=2 npm run vk:token
```

## Локальное хранение токенов

Токены сохраняются в папку `tokens/` с метаданными:

```json
{
  "browserId": 1,
  "accessToken": "vk1.a....",
  "expiresIn": 86400,
  "expiresAt": "2026-06-19T12:00:00.000Z",
  "userId": 123456789,
  "email": "user@mail.ru",
  "appId": 6287487,
  "savedAt": "2026-06-18T12:00:00.000Z"
}
```

### Использование в коде

```typescript
import { getAccessToken, loadToken, loadAllTokens } from './token/index.js';

const token = await getAccessToken(1); // активный токен браузера #1
const saved = await loadToken(2);      // полные данные браузера #2
const all = await loadAllTokens();     // все сохранённые токены
```

## Порядок использования

1. `npm run vk:session -- --browser 1` — войти в VK
2. `npm run vk:token -- --browser 1` — получить и сохранить токен
3. `npm run vk:get -- --browser 1` — использовать токен в других скриптах

Старые файлы `.vk-token-*.json` автоматически мигрируют в `tokens/` при первом чтении.

## AI-подсказка ответа через Ollama

Кнопка `AI` в чате предлагает текст ответа на основе последних 50 сообщений и FAQ.

### 1) Подготовить Ollama

```bash
ollama serve
ollama pull gemma4
```

По умолчанию используется:
- `OLLAMA_BASE_URL=http://localhost:11434`
- `OLLAMA_MODEL=gemma4`

При необходимости можно переопределить переменные окружения перед запуском сервера.

### 2) Заполнить FAQ

Отредактируйте файл `data/faq.md`. Этот файл добавляется в системный промпт для модели и определяет стиль и правила ответов.

### 3) Запустить проект

```bash
npm run dev
```

Откройте чат в web-интерфейсе, нажмите `AI`, затем при необходимости поправьте текст и отправьте обычной кнопкой `Отправить`.

## Запуск в Docker

Проект можно легко развернуть на любом устройстве (включая серверы без монитора) с помощью Docker. В контейнер встроена поддержка **noVNC**, чтобы вы могли пройти авторизацию в браузере прямо через веб-интерфейс. Также в сборку включена **Ollama** для локальной работы нейросети, генерирующей ответы.

### 1) Сборка и запуск

Выполните команду в корне проекта:
```bash
docker compose up -d --build
```

### 2) Загрузка модели в Ollama

Так как Ollama теперь работает внутри Docker, при первом запуске ей нужно скачать модель (по умолчанию используется `gemma4` — если в коде или настройках прописана она, либо `llama3`, `mistral` и т.д.). Выполните эту команду:

```bash
docker exec -it vk-chat-bot-ollama-1 ollama pull gemma4
```
*(Имя контейнера может слегка отличаться, например `vk-chat-bot_ollama_1`. Его можно посмотреть через `docker ps`)*.

### 3) Использование

- **Веб-интерфейс бота:** доступен по адресу `http://localhost:8080`.
- **Авторизация (VNC):** При добавлении или обновлении токена (кнопка `Начать настройку` в веб-интерфейсе) на фоне открывается Chromium. Чтобы залогиниться в VK, откройте `http://localhost:6080/vnc.html`, нажмите "Connect" и введите свои данные в появившемся окне браузера.

### 4) Данные и видеокарты (GPU)

При запуске через Docker Compose создадутся папки-тома, в которых будут храниться профили браузера и токены (`.browser-profile-*`, `tokens`, `data`). Модели Ollama сохраняются в отдельный именованный docker volume (`ollama_data`).

> **Важно:** По умолчанию Ollama в Docker работает на процессоре (CPU), что может быть медленно. Если у вас есть видеокарта от NVIDIA и установлены драйвера `nvidia-container-toolkit`, откройте файл `docker-compose.yml` и раскомментируйте блок `deploy` внутри сервиса `ollama`, чтобы ускорить генерацию ответов.
